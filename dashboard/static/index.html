Command transport and safety limitations

Commands use picocar/vehicle1/command, QoS 0, without retain. A successful API response means publication queued. Delivery, controller acceptance and physical execution remain unverified. STOP is a remote MQTT command, not a hardware emergency stop.

A fresh heartbeat records a recent status-topic message. It does not establish sensor validity, actuator readiness or a working controller handoff.

Protocol, timing and validity limitations

The existing text envelope exposes src, type, seq, value1 and value2. Internal flags are not transmitted by the current firmware. Unknown types remain available as raw data.

Telemetry observation time belongs to this browser, not the device or broker. An unchanged payload cannot prove that transmission stopped or continued. Reloading clears browser observations and saved session values.

The backend caches only the latest message on each topic. Fresh heartbeat means the API-reported age is below 15 seconds; it does not reject retained or unvalidated status payloads.
